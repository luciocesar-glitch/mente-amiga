# Cuidar+

Aplicativo React + Vite + Tailwind CSS para apoiar a organização da rotina de pessoas com Alzheimer, familiares e cuidadores.

## Desenvolvimento

Instale as dependências com `pnpm install` e inicie o servidor com `pnpm dev`.

## Estrutura principal

- `src/main.tsx` — ponto de entrada da aplicação.
- `src/App.tsx` — telas de acesso, painel da rotina e componentes da interface.
- `src/index.css` — estilos globais e tema Tailwind CSS.
- `public/favicon.png` — ícone da aplicação.
- `vite.config.ts` — configuração independente do Vite.

## Scripts

- `pnpm dev` — servidor de desenvolvimento.
- `pnpm build` — compilação de produção.
- `pnpm preview` — pré-visualização da compilação.
- `pnpm format` — formatação do código.
