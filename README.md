# Cuidar+

Aplicativo web de apoio diário para pessoas com Alzheimer, familiares e cuidadores. O Cuidar+ organiza lembretes de remédios, alimentação, estudos e outras atividades, com leitura em voz alta e notificações do navegador.

## Como executar

```bash
pnpm install
pnpm dev
```

Para gerar a versão de produção:

```bash
pnpm build
pnpm preview
```

## Observação

Este projeto é uma interface demonstrativa. O login, os lembretes e as preferências são executados localmente no navegador e não substituem orientação médica ou um sistema de emergência.
